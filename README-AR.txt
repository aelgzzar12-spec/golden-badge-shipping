موقع شركة شحن الوسام الذهبي — تعليمات التشغيل
=============================================

الملفات:
- index.html: الصفحة الرئيسية ونموذج طلب عرض سعر.
- track.html: تتبع الشحنة برقم تتبع.
- admin.html: لوحة إدارة الطلبات.
- config.js: رابط Supabase والمفتاح العام ورقم واتساب.
- assets/: ملفات التنسيق والوظائف.
- supabase-setup.sql: جداول وسياسات الأمان ودالة التتبع.

1) إعداد Supabase
- أنشئ مشروع Supabase جديدًا أو استخدم مشروع الشركة.
- افتح SQL Editor، والصق ملف supabase-setup.sql كاملًا، ثم Run.
- من Project Settings > API انسخ Project URL والمفتاح Publishable (أو anon القديم).
- ضع القيم في config.js. لا تضع service_role أو أي مفتاح سري في الموقع.
- ضع رقم واتساب الشركة في whatsappNumber بصيغة دولية بدون + أو مسافات، مثال توضيحي فقط: 2010XXXXXXXX.

2) حساب الإدارة
- من Authentication > Users أنشئ حساب الإدارة.
- يجب تعيين app_metadata.role = admin لهذا المستخدم من وسيلة إدارية موثوقة (مثل Supabase Admin API في بيئة آمنة أو إجراء إداري موثوق). لا تضع service_role key في ملفات الواجهة.
- لا يكفي إنشاء مستخدم عادي؛ لوحة الإدارة تتحقق من app_metadata.role.
- اختبر تسجيل الدخول بعد تحديث الجلسة.

3) تجربة الموقع
- افتح index.html من خلال استضافة أو خادم محلي. يفضّل عدم الاعتماد على فتح file:// مباشرة.
- أرسل طلبًا تجريبيًا، وتحقق من ظهوره في public.shipping_requests.
- من لوحة الإدارة عيّن tracking_number فريدًا مثل WG-2026-00001 وحدد الحالة ثم احفظ.
- افتح track.html واختبر رقم التتبع.

4) النشر
- ارفع الملفات إلى مستودع GitHub.
- استورد المستودع إلى Vercel.
- لا توجد عملية بناء مطلوبة (Static HTML).
- أضف دومين الشركة لاحقًا بعد امتلاكه.

قبل النشر الفعلي:
- استبدل النصوص العامة باسم الشركة القانوني وبياناتها المؤكدة.
- أضف رقم الهاتف وواتساب والبريد والعنوان وساعات العمل.
- حدّد الدول وخطوط السير التي تعمل بها الشركة فعلًا.
- أضف سياسة خصوصية وشروط الخدمة، وتأكد من ملاءمتها للقوانين المعمول بها.
- اختبر سياسات RLS وحساب الإدارة والتتبع قبل نشر بيانات حقيقية.
- لا تعرض وعودًا بوقت وصول أو تغطية دول أو خدمات تخليص جمركي إلا إذا أكّدتها الشركة.
- التتبع هنا يعرض آخر حالة أدخلها موظف الإدارة؛ لا يوجد GPS حي للشاحنات.

ملاحظات أمنية:
- مفتاح Supabase العام مصمم للاستخدام بالواجهة مع RLS مضبوط.
- لا تضع service_role key في config.js أو أي ملف يصل للمتصفح.
- نموذج الزوار لا يتيح قراءة الطلبات؛ التتبع العام يعيد حقولًا محدودة فقط.
- يلزم إضافة حماية إضافية من الرسائل المزعجة (مثل CAPTCHA/Rate limiting) قبل الاستخدام التجاري الواسع.
